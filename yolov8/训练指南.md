# YOLOv8 GPU 训练完整指南

## 📋 前置要求

### 1. 硬件要求
- **NVIDIA GPU**（支持 CUDA）
- **显存**：建议 6GB+（batch=16），显存不足可减小 batch 大小

### 2. 软件环境

#### 2.1 安装 NVIDIA 驱动
```powershell
# 检查驱动版本
nvidia-smi
```
确保驱动版本 >= 450.80（支持 CUDA 11.0+）

#### 2.2 安装 CUDA 和 cuDNN
- **CUDA**：推荐 11.8 或 12.1
- **cuDNN**：与 CUDA 版本匹配
- 下载地址：https://developer.nvidia.com/cuda-downloads

#### 2.3 安装 PyTorch（GPU 版本）
```powershell
# 访问 https://pytorch.org/get-started/locally/
# 选择你的 CUDA 版本，例如 CUDA 11.8：
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

# 或 CUDA 12.1：
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

#### 2.4 安装 Ultralytics YOLOv8
```powershell
pip install ultralytics
```

### 3. 验证 GPU 环境
```powershell
python -c "import torch; print('CUDA 可用:', torch.cuda.is_available()); print('GPU 名称:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'N/A')"
```

**预期输出**：
```
CUDA 可用: True
GPU 名称: NVIDIA GeForce RTX 5090
```

## 📁 数据集准备

### 1. 数据集结构
确保数据集按以下结构组织：
```
yolov8/
├── xun/
│   ├── images/
│   │   ├── train/     # 训练图片
│   │   └── val/        # 验证图片
│   └── labels/
│       ├── train/      # 训练标注（.txt 格式，YOLO 格式）
│       └── val/        # 验证标注
└── data.yaml           # 数据集配置文件
```

### 2. 标注格式（YOLO 格式）
每个图片对应一个 `.txt` 文件，格式：
```
class_id center_x center_y width height
```
- `class_id`：类别索引（0-6，对应 data.yaml 中的 names）
- `center_x, center_y`：边界框中心点坐标（归一化到 0-1）
- `width, height`：边界框宽高（归一化到 0-1）

**示例**：
```
0 0.5 0.5 0.3 0.4
1 0.2 0.3 0.1 0.2
```

### 3. 检查 data.yaml
确保 `data.yaml` 配置正确：
```yaml
path: D:\yolov8\xun  # 数据集根目录（绝对路径或相对路径）
train: images/train   # 训练图片相对路径
val: images/val       # 验证图片相对路径
nc: 7                 # 类别数量
names: ["垃圾","泡沫箱","船","塑料瓶","易拉罐","树叶","树枝"]  # 类别名称
```

**注意**：如果使用相对路径，确保从 `yolov8/` 目录运行训练脚本。

## 🚀 训练步骤

### 方法一：使用提供的训练脚本（推荐）

1. **进入 yolov8 目录**
```powershell
cd yolov8
```

2. **运行 GPU 训练脚本**
```powershell
python train_gpu.py
```

### 方法二：使用 Ultralytics CLI

```powershell
cd yolov8
yolo detect train data=data.yaml model=yolov8n.pt epochs=500 imgsz=640 batch=16 device=0 amp=True cache=True
```

### 方法三：使用 Python 代码

```python
from ultralytics import YOLO

model = YOLO('yolov8n.pt')
model.train(
    data='data.yaml',
    epochs=500,
    imgsz=640,
    batch=16,
    device=0,  # GPU
    amp=True,
    cache=True
)
```

---

## ⚙️ 训练参数说明

### 核心参数
- **epochs**：训练轮数（建议 300-500，根据数据集大小调整）
- **imgsz**：输入图像尺寸（640 是标准尺寸，可尝试 416 或 832）
- **batch**：批次大小（显存不足时减小：16 → 8 → 4）
- **device**：`0` 使用 GPU，`'cpu'` 使用 CPU
- **amp**：自动混合精度（加速训练，节省显存）

### 优化参数
- **lr0**：初始学习率（默认 0.01，可尝试 0.001-0.01）
- **patience**：早停耐心值（50 轮无改善则停止）
- **optimizer**：优化器（SGD/Adam/AdamW）

### 数据增强
- **mosaic**：Mosaic 增强概率（0.0-1.0）
- **mixup**：Mixup 增强概率（0.0-1.0）
- **fliplr**：左右翻转概率（0.5）

## 🔧 常见问题排查

### 问题 1：CUDA out of memory（显存不足）
**解决方案**：
1. 减小 batch 大小：`batch=8` 或 `batch=4`
2. 减小图像尺寸：`imgsz=416`
3. 关闭缓存：`cache=False`
4. 关闭混合精度：`amp=False`（不推荐）

### 问题 2：训练速度慢
**检查**：
- 确认使用 GPU：`device=0`
- 启用混合精度：`amp=True`
- 启用缓存：`cache=True`（需要足够内存）
- 增加 workers：`workers=8`（根据 CPU 核心数）

### 问题 3：loss 不下降或过拟合
**解决方案**：
- 增加数据增强：`mosaic=1.0`, `mixup=0.15`
- 调整学习率：`lr0=0.001`
- 增加权重衰减：`weight_decay=0.001`
- 使用早停：`patience=50`

### 问题 4：类别不平衡
**解决方案**：
- 使用类别权重（在 data.yaml 中配置）
- 增加少数类别的数据
- 使用 Focal Loss（YOLOv8 默认已优化）

## 📈 训练建议

### 数据集大小建议
- **小数据集**（< 1000 张）：epochs=300-500，使用预训练模型
- **中等数据集**（1000-5000 张）：epochs=200-300
- **大数据集**（> 5000 张）：epochs=100-200

### 训练时间估算
- **GPU RTX 3060**（12GB）：batch=16，约 2-4 小时/100 epochs
- **GPU RTX 4090**（24GB）：batch=32，约 1-2 小时/100 epochs
- **CPU**：约 10-20 倍 GPU 时间

### 最佳实践
1. ✅ 使用 GPU 训练（device=0）
2. ✅ 启用混合精度（amp=True）
3. ✅ 使用早停（patience=50）
4. ✅ 定期保存检查点（save_period=10）
5. ✅ 监控验证集 mAP，选择最佳模型
